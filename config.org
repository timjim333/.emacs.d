* About

My Emacs configuration, written as a literate Org file. The =init.el=
stub tangles the code blocks into =config.el= whenever this file is newer,
then loads it; saving this file inside Emacs tangles it straight away (see
[[*Tangle on save][Tangle on save]]). =config.el= isn't in git
([[file:docs/adr/0003-literate-config-with-untracked-tangle.md][ADR 0003]]).

This is a fresh rebuild aimed at a notes and knowledge system in Org mode,
plus light IDE-style coding. The roadmap is in [[file:PLAN.md][PLAN.md]];
the previous config is at the =old-config= tag.

Target: Emacs 31.1, pgtk build, on Fedora KDE (Wayland).

** Prerequisites (Fedora)

#+begin_src sh :tangle no
sudo dnf install ripgrep fd-find enchant2-devel pkgconf \
     rsms-inter-fonts jetbrains-mono-fonts \
     texlive-latex texlive-dvipng texlive-wrapfig texlive-ulem texlive-capt-of
#+end_src

- =ripgrep= / =fd= are used by Consult for searching.
- =enchant2-devel= and =pkgconf= let Jinx build its spell-checking module.
- Inter (prose) and JetBrains Mono (code) are the fonts used below.
- LaTeX and =dvipng= render equation previews; =wrapfig=, =ulem=, and
  =capt-of= are in Org's default preamble, and without them every
  preview fails.
- Nerd Font icons: run =M-x nerd-icons-install-fonts= once.

* Start-up

=early-init.el= is hand-written, not tangled, because it runs before
anything could tangle it. It sets the State paths outside the repo
([[file:docs/adr/0002-xdg-layout-state-outside-the-repo.md][ADR 0002]]),
hides the UI elements before the first frame, and relaxes the garbage
collector while starting.

** Tangle on save

Saving this file re-tangles =config.el=, so =load-file= picks up a change
without a restart.

#+begin_src emacs-lisp
(defun tim/tangle-config ()
  "Tangle config.org when it is saved."
  (when (equal (buffer-file-name)
               (expand-file-name "config.org" user-emacs-directory))
    ;; Avoid running hooks while tangling.
    (let ((prog-mode-hook nil))
      (org-babel-tangle))))

(add-hook 'after-save-hook #'tim/tangle-config)
#+end_src

* Housekeeping
** Keep State out of the repo

[[https://github.com/emacscollective/no-littering][no-littering]] moves the files packages create (history, caches, backups)
into =var/= and =etc/=, which =early-init.el= puts under
=~/.local/share/emacs/=. It has to load before other packages.

#+begin_src emacs-lisp
(use-package no-littering
  :demand t
  :config
  (no-littering-theme-backups))
#+end_src

Customize writes to its own file, which =early-init.el= puts under
=~/.local/share/emacs/= because Emacs writes it. Personal settings that
shouldn't be in git (API keys, calendar IDs) go in =private.el= in this
folder, which =.gitignore= leaves out.

#+begin_src emacs-lisp
(dolist (file (list custom-file
                    (expand-file-name "private.el" user-emacs-directory)))
  (when (file-exists-p file)
    (load file nil t)))
#+end_src

** Fonts

Inter for prose (=variable-pitch=) and JetBrains Mono for code
(=default= and =fixed-pitch=). Org buffers will mix them in the Org step.

#+begin_src emacs-lisp
(defvar tim/font-height 115)

(defun tim/set-fonts ()
  "Set fonts, skipping any that aren't installed."
  (when (member "JetBrains Mono" (font-family-list))
    (set-face-attribute 'default nil :family "JetBrains Mono" :height tim/font-height)
    (set-face-attribute 'fixed-pitch nil :family "JetBrains Mono" :height 1.0))
  (when (member "Inter" (font-family-list))
    (set-face-attribute 'variable-pitch nil :family "Inter" :height 1.05)))

;; Fonts can only be set once a graphical frame exists, which matters when
;; running as a daemon.
(if (daemonp)
    (add-hook 'server-after-make-frame-hook #'tim/set-fonts)
  (tim/set-fonts))
#+end_src

** Spell checking

[[https://github.com/minad/jinx][Jinx]] checks only the visible part of the buffer, so it's fast. =M-$=

  :hook (emacs-startup . global-jinx-mode)
  :custom (jinx-languages "en_GB")
  :bind (("M-$"   . jinx-correct)
         ("C-M-$" . jinx-languages)))

* Org basics

Org itself is built in. Notes live in =~/org/=
([[file:docs/design-notes.md][design notes]], "Notes layout").

** Rendering

Only =x_{i}= and =e^{2}= become sub- and superscripts, so =snake_case=
stays plain; =org-pretty-entities= draws them, and =\alpha= as α.
Emphasis markers are hidden. Previews are rendered when a file opens;
their images go to the cache, not beside the note (=early-init.el=).

The images in =~/.cache/emacs/org-latex/= are only a speed-up: each is
named after a hash of its equation, so Emacs reuses it next time and
redraws any that are missing. Don't sync or back them up; the =.org=
file is the source. Nothing removes images for equations you edit or
delete, but each is under 1 kB, so delete the folder whenever you like.

#+begin_src emacs-lisp
(use-package org
  :ensure nil
  :custom
  (org-directory "~/org/")
  (org-use-sub-superscripts '{})
  (org-export-with-sub-superscripts '{})
  (org-pretty-entities t)
  (org-hide-emphasis-markers t)
  (org-startup-with-latex-preview t)
  :config
  (plist-put org-format-latex-options :scale 1.5))
#+end_src

** Tags

Tags are for finding things later, on an axis that the file a note sits
in and its links don't already give. This table is the vocabulary, with
each tag's meaning; the code below reads it, so edit it here. =C-c C-q=
tags a heading by key; =TAB= there takes a one-off tag. Org tags allow
only letters, digits, =_=, =@=, =#=, and =%=, so join words with =_=.

| Type    | Says                     | Inherited | Example                                 |
|---------+--------------------------+-----------+-----------------------------------------|
| kind    | what the heading is      | no        | a =paper='s section notes aren't papers |
| subject | what it's about          | yes       | a =travel= trip's TODOs are travel      |
| context | where a task can be done | yes       | =@errand= on a shopping list            |

Rules of thumb:
- Tag a subject only if its notes would be spread across files; a topic
  file is its own tag.
- One concept, one tag: singular, lower case, British English.
- Leave out what the file or a TODO keyword already says. Status
  (draft, done) is a TODO keyword, not a tag.

#+name: tim-tags
| Tag       | Type    | Key | Meaning                                                  |
|-----------+---------+-----+----------------------------------------------------------|
| idea      | kind    | i   | A thought to develop later                               |
| paper     | kind    | p   | A research paper, or notes on one                        |
| howto     | kind    | h   | Steps for doing something (code, design, PC build)       |
| meeting   | kind    | m   | Notes from a meeting or call                             |
| aviation  | subject | a   | Aircraft, their design, and the technical side of flying |
| travel    | subject | t   | Trips and holiday ideas                                  |
| finance   | subject | f   | Money, tax, and investments                              |
| @computer | context | c   | A task that needs glacier                                |
| @phone    | context | o   | A call to make                                           |
| @errand   | context | e   | A task done out and about                                |

#+begin_src emacs-lisp :var tags=tim-tags
(setq org-tag-persistent-alist
      (mapcar (lambda (row) (cons (nth 0 row) (string-to-char (nth 2 row))))
              tags)
      org-tags-exclude-from-inheritance
      (mapcar #'car (seq-filter (lambda (row) (equal (nth 1 row) "kind"))
                                tags)))
#+end_src

* Completion

The minibuffer stack, all by the same small family of packages that build
on Emacs' own completion:

- [[https://github.com/minad/vertico][Vertico]]: vertical candidate list.
- [[https://github.com/tumashu/vertico-posframe][vertico-posframe]]: shows it as a pop-up in the centre of the frame.
- [[https://github.com/oantolin/orderless][Orderless]]: type space-separated parts in any order.
- [[https://github.com/minad/marginalia][Marginalia]]: annotations (docstrings, file sizes) next to candidates.
- [[https://github.com/minad/consult][Consult]]: search and navigation commands with live preview.
- [[https://github.com/oantolin/embark][Embark]]: act on the candidate at point (=C-.=).
- [[https://github.com/minad/corfu][Corfu]]: in-buffer completion pop-up.
