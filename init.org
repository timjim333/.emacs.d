* About

My Emacs configuration, written as a literate Org file. Code blocks are
tangled into =early-init.el= and =init.el= every time this file is saved (see
[[*Tangle on save][Tangle on save]]), and both generated files are committed so a fresh
machine can start from a plain clone.

This is a fresh rebuild aimed at a notes and knowledge system in Org mode,
plus light IDE-style coding. The previous config (forked from
[[https://github.com/SophieBosio/.emacs.d][SophieBosio/.emacs.d]]) is in the git history.

Target: Emacs 31.1, pgtk build, on Fedora KDE (Wayland).

** Build order

Each step adds a top-level section to this file.

1. [X] Skeleton: startup, packages, housekeeping, look, completion, git
2. [ ] Org basics: directories, visuals, equations, images, Babel
3. [ ] Notes: org-node, daily notes, capture templates, graph
4. [ ] Tasks, agenda and Google Calendar (org-gcal)
5. [ ] Coding: eglot, tree-sitter, ruff, formatting, debugging, direnv
6. [ ] References: citar, org-noter
7. [ ] Extras: KDE capture shortcut, org-protocol, gptel

* Start-up
** Early init

=early-init.el= runs before the package system and the first frame are set
up, so it's the place to hide UI elements (no flicker) and to relax the
garbage collector while starting.

#+begin_src emacs-lisp :tangle early-init.el
;;; early-init.el --- Tangled from init.org -*- lexical-binding: t -*-

;; Collect garbage rarely while starting, then go back to a sane value.
(setq gc-cons-threshold most-positive-fixnum
      gc-cons-percentage 0.6)
(add-hook 'emacs-startup-hook
          (lambda ()
            (setq gc-cons-threshold (* 64 1024 1024)
                  gc-cons-percentage 0.1)))

;; Language servers send a lot of data; read it in bigger chunks.
(setq read-process-output-max (* 4 1024 1024))

;; Prefer newer .el files over stale .elc files.
(setq load-prefer-newer t)

;; No menu bar, tool bar or scroll bars, set before the first frame is drawn.
(setq default-frame-alist
      '((menu-bar-lines       . 0)
        (tool-bar-lines       . 0)
        (vertical-scroll-bars . nil)
        (internal-border-width . 16)))

(setq frame-inhibit-implied-resize t
      frame-resize-pixelwise       t
      inhibit-startup-screen       t
      initial-scratch-message      nil)

;; Native compilation warnings are noisy and almost always harmless.
(setq native-comp-async-report-warnings-errors 'silent)

;; On pgtk, a shorter event timeout makes child frames (the pop-up
;; completion window) feel snappier.
(when (boundp 'pgtk-wait-for-event-timeout)
  (setq pgtk-wait-for-event-timeout 0.001))
#+end_src

** Packages

=package.el= and =use-package= are built in. GNU ELPA and NonGNU ELPA are
preferred, with MELPA for everything else.

#+begin_src emacs-lisp
(require 'package)
(setq package-archives
      '(("gnu"    . "https://elpa.gnu.org/packages/")
        ("nongnu" . "https://elpa.nongnu.org/nongnu/")
        ("melpa"  . "https://melpa.org/packages/"))
      package-archive-priorities
      '(("gnu" . 30) ("nongnu" . 20) ("melpa" . 10)))
(package-initialize)

(require 'use-package)
(setq use-package-always-ensure t)
#+end_src

** Tangle on save

Saving this file re-tangles =init.el= and =early-init.el=.

#+begin_src emacs-lisp
(defun tim/tangle-init ()
  "Tangle init.org when it is saved."
  (when (equal (buffer-file-name)
               (expand-file-name "init.org" user-emacs-directory))
    ;; Avoid running hooks while tangling.
    (let ((prog-mode-hook nil))
      (org-babel-tangle))))

(add-hook 'after-save-hook #'tim/tangle-init)
#+end_src

* Housekeeping
** Keep ~/.emacs.d tidy

[[https://github.com/emacscollective/no-littering][no-littering]] moves the files packages create (history, caches, backups)
into =var/= and =etc/=. It has to load before other packages.

#+begin_src emacs-lisp
(use-package no-littering
  :demand t
  :config
  (no-littering-theme-backups))
#+end_src

Customize writes to its own file, and personal settings that shouldn't be in
git (API keys, calendar IDs) go in =private.el=. Both are git-ignored.

#+begin_src emacs-lisp
(setq custom-file (expand-file-name "custom.el" user-emacs-directory))
(dolist (file (list custom-file
                    (expand-file-name "private.el" user-emacs-directory)))
  (when (file-exists-p file)
    (load file nil t)))
#+end_src

** Fonts

Inter for prose (=variable-pitch=) and JetBrains Mono for code
(=default= and =fixed-pitch=). Org buffers will mix them in the Org step.

#+begin_src emacs-lisp
(defvar tim/font-height 115)

(defun tim/set-fonts ()
  "Set fonts, skipping any that aren't installed."
  (when (member "JetBrains Mono" (font-family-list))
    (set-face-attribute 'default nil :family "JetBrains Mono" :height tim/font-height)
    (set-face-attribute 'fixed-pitch nil :family "JetBrains Mono" :height 1.0))
  (when (member "Inter" (font-family-list))
    (set-face-attribute 'variable-pitch nil :family "Inter" :height 1.05)))

;; Fonts can only be set once a graphical frame exists, which matters when
;; running as a daemon.
(if (daemonp)
    (add-hook 'server-after-make-frame-hook #'tim/set-fonts)
  (tim/set-fonts))
#+end_src

* Help

=which-key= (built in since Emacs 30) shows the keys available after a
prefix. [[https://github.com/Wilfred/helpful][helpful]] gives richer help buffers.

(use-package which-key
  :ensure nil
  :config (which-key-mode 1))

  :bind (([remap describe-function] . helpful-callable)
         ([remap describe-variable] . helpful-variable)
         ([remap describe-key]      . helpful-key)

* Completion

The minibuffer stack, all by the same small family of packages that build
on Emacs' own completion:

- [[https://github.com/minad/vertico][Vertico]]: vertical candidate list.
- [[https://github.com/tumashu/vertico-posframe][vertico-posframe]]: shows it as a pop-up in the centre of the frame.
- [[https://github.com/oantolin/orderless][Orderless]]: type space-separated parts in any order.
- [[https://github.com/minad/marginalia][Marginalia]]: annotations (docstrings, file sizes) next to candidates.
- [[https://github.com/minad/consult][Consult]]: search and navigation commands with live preview.
- [[https://github.com/oantolin/embark][Embark]]: act on the candidate at point (=C-.=).
- [[https://github.com/minad/corfu][Corfu]]: in-buffer completion pop-up.
